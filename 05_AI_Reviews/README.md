# AI Reviews

Save independent reviews here, one file per assistant and task. Suggested naming:

- `YYYY-MM-DD_task-name_chatgpt.md`
- `YYYY-MM-DD_task-name_claude.md`
- `YYYY-MM-DD_task-name_gemini.md`

Ask each assistant to cite exact file paths and code locations, separate facts from assumptions, and state when evidence is insufficient. Do not include secrets or entire `.env` files.
